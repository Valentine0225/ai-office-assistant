# AI Office Assistant

一个基于 Python 和本地大模型的 AI 办公效率助手，支持文档总结、日报生成和会议纪要整理，适用于日常办公和学习场景。

## Features

- 文本自动总结
- 日报自动生成
- 会议纪要整理
- 支持直接输入文本
- 支持读取 `.txt` 文件
- 基于 CLI 命令行交互

## Tech Stack

- Python
- Ollama
- Qwen2.5
- OpenAI-compatible API
- Prompt Engineering
